企业配置说明

操作说明与配置流程

fly云强调简洁高效的配置体验。完成套餐订阅后，按照以下步骤即可在各平台启用加速。整个流程通常只需几分钟，新手也可对照完成。配置的核心是获取订阅链接并正确导入客户端。

第一步：获取机场订阅链接

在 fly云官网完成套餐选择与支付后，用户中心会生成专属订阅 URL。复制该链接，后续导入客户端使用。请妥善保管订阅地址，勿公开分享，以免流量被占用或产生安全风险。

第二步：下载并安装客户端

根据设备选择对应客户端。Windows 推荐 Clash for Windows 或 Clash Verge；macOS 可用 ClashX 或 Surge；iOS 常用 Shadowrocket 或 Quantumult X；Android 可选 Clash Meta for Android 或 v2rayNG。请从官方仓库或可信应用商店获取，确保版本较新，不要安装来路不明的修改包。

第三步：导入订阅配置

打开客户端，找到订阅或配置管理入口，粘贴 fly云提供的订阅链接，点击更新。部分客户端支持二维码扫描导入。更新成功后即可看到节点列表。若提示失败，检查链接完整性与网络环境后再试。

第四步：选择节点并连接

根据需求选择延迟较低或专线节点。游戏场景优先 IPLC 或游戏优化节点；流媒体选择解锁节点。开启系统代理或 TUN 模式，测试连通性。可先用浏览器访问常用站点确认是否生效。

第五步：日常维护与优化

定期在客户端更新订阅以获取最新节点。如遇个别节点不稳定，切换其他线路。关注流量使用情况，接近限额时可升级套餐。遇到问题可通过工单联系支持，旗舰版与团队版享有更优先的响应。

常见问题 FAQ

fly云(flycloud) 是官方机场服务吗？如何保证安全？

fly云是专注网络加速的服务品牌，通过官网提供套餐与订阅。我们强调使用标准协议与主流客户端，建议用户仅从可信渠道下载软件，并定期更新。官方身份以本站信息与订阅后台为准，请勿轻信非官网渠道的所谓低价或破解来源，以免造成账号或设备风险。

各套餐流量和设备数具体怎么算？年付有什么好处？

基础版每月 100GB、最多 3 台设备同时在线；旗舰版 300GB、5 台设备，含更好解锁与 IPLC；团队版 1000GB、20 台。流量按订阅周期重置。年付价格相当于每月更低，适合长期使用，且减少续费操作。具体以购买时页面显示为准，可按实际用量在后续周期调整。

如何导入订阅？Clash 和 Shadowrocket 操作有区别吗？

通用方式是复制订阅链接，在客户端的订阅管理中新增并更新。Clash 系通常在 Profiles 添加 URL 后 Download。Shadowrocket 点击右上角扫描或粘贴链接。Quantumult X 需在节点订阅处添加。导入后选择规则模式效果更佳。详细分步见本页配置流程，按软件界面提示操作即可。

fly云能解锁 Netflix、ChatGPT 或游戏加速吗？

旗舰版强调全节点原生流媒体解锁，覆盖常见国际平台。游戏方面提供 IPLC 专线优化，降低延迟。具体解锁效果因节点与平台策略而异，建议选择对应优化线路。基础版提供基础流媒体支持。访问 AI 服务取决于节点质量，优质线路通常更稳定，可多试几条节点。

连接失败或速度慢时该如何处理？

首先更新订阅获取最新节点，切换其他线路测试。检查本地网络、关闭可能冲突的防火墙或杀毒软件。确认客户端模式正确（系统代理或增强模式）。若持续异常，通过优先工单（旗舰及以上）反馈节点名称与错误信息，客服会协助排查。避免长期使用过期配置。

支持退款或套餐更换吗？多设备超限会怎样？

具体售后政策以购买时说明为准。一般支持在未大量使用流量的短时间内协商处理。升级套餐通常可补差价。同时在线设备超过套餐上限时，新设备可能无法连接或挤占已有会话，建议按实际终端数量选择版本。团队版有专属客户经理，沟通更便捷。

在哪里可以获取最新官网信息和客户端更新提醒？

请收藏本官方网站页面，套餐、节点说明与教程更新会在此同步。客户端本身请关注各开源项目的发布页以获取安全更新。fly云侧重点在订阅稳定性与线路质量，配合用户自行维护客户端版本，二者结合才能获得更顺畅的加速体验。
